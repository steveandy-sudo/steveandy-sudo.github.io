## 연구 질문

**인프라 카메라 정보를 추가하면 주차 차량 뒤에 가려진 보행자에 대한 E2E 차량의 대응이 어떻게 달라지는가?**

팀은 축소 차량에서 **Camera-only와 V2I 정보 활용 E2E 모델을 비교**할 계획이다. Camera-only는 차량 카메라와 차량 상태를 입력으로 사용하는 기준 모델이다. V2I 정보 활용 모델은 도로변 카메라가 차폐 영역을 관측해 보행자 정보를 차량으로 보내고, 차량이 이를 차량 카메라 입력 및 차량 상태와 결합하는 구상이다.

이번 학기에는 관련 연구 요약, 예비 설계, 중간발표를 진행한다. 데이터 수집, 모델 학습, 차량 평가는 후속 단계에서 진행할 계획이다.

## 관련 연구 검토와 프로젝트 범위

UniV2X에서 차량·인프라 융합과 개루프 평가를 다룬 부분을 검토하고, 프로젝트 범위 설정에 참고할 수 있도록 내용을 요약했다. 축소 차량에서 계획 중인 폐루프 비교를 위해 단순화한 융합 방식을 제안했다.

비교 실험에서는 보행자 정보를 더 일찍 제공했을 때 차량의 감속 시점과 확보되는 정지 여유가 달라지는지 살펴볼 계획이다.

## 중간발표 예비 설계

팀원들과 논의한 뒤 중간발표 자료를 작성했다. 자료에는 팀의 시나리오와 시스템 구상, 보행자 위험도 평가, 제동 여유, 학습 데이터 요구사항을 정리했다.

| 설계 항목 | 현재 제안 |
| --- | --- |
| 대표 시나리오 | 통제된 직선 구간의 차량 1대, 보행자 1명, 차폐물 |
| 운행 조건 | 주간, 맑은 날씨, 건조한 노면, 저속 주행, 위치 추정과 V2I 수신의 정상 동작 |
| 인프라 카메라 | 여러 주차 공간을 비스듬히 내려다보는 높은 위치의 시야 확보, 현장에서 설치 위치·각도 검토 예정 |
| 보행자 정보 | 위치, 움직임, 관측 기반 위험도, 촬영 시각 |
| 차량 주행계획 | 차량 카메라 입력 및 차량 상태 활용, V2I 정보 활용 모델에 인프라 정보 추가 |
| 출력 | 하위 제어기에 전달할 웨이포인트와 목표 속도 |

팀은 주차 차량 사이의 한 틈을 관측하던 카메라 구상을 여러 주차 공간을 높은 위치에서 내려다보는 방식으로 변경했다. 향후 현장 평가에서 설치 위치, 시야각, 보행자 가시성을 검토할 계획이다.

제안한 인터페이스는 **인프라 관측 정보**와 **학습 목표값**을 구분한다.

| 정보 | 활용안 |
| --- | --- |
| 객체 위치, 속도, 보행자 위험도, 촬영 시각 | V2I 정보 활용 E2E 모델의 추가 입력 |
| 차량 경로와의 중첩 및 제동 여유 | 목표 속도 라벨 생성을 위한 전문가 규칙의 입력 |
| 전문가 규칙 기반 목표 속도 및 궤적 목표값 | 두 모델이 공통으로 사용하는 학습 목표값 |

보행자 위험도 특징은 인프라의 관측 정보를 나타낸다. 전문가 규칙 기반 라벨 생성에서는 차량 경로와 정지 여유도 고려해 감속·정지·재출발 목표를 정한다.

## 보행자 위험도와 목표 속도 라벨

예비 설계는 다음 세 요소를 결합한다.

- **보행자 상태:** 연석을 기준으로 한 위치와 도로에 접근하거나 도로에서 멀어지는 움직임.
- **경로 중첩:** 보행자 점유 영역과 차량의 계획 경로가 겹치는지 여부.
- **제동 여유:** 시스템 지연, 제동 거리, 안전 여유를 고려했을 때 확보되는 거리.

필요 정지 거리는 `d_req = v × T_system + D_brake(v) + M`으로 나타낸다. 팀은 차량의 제동 특성과 시스템 처리 시간을 측정해 설계값을 구체화할 계획이다.

전문가 규칙 기반 라벨 생성 계획은 이 정보를 바탕으로 **조기 감속, 경로가 점유된 동안의 정지 유지, 경로가 비워진 뒤의 재출발**을 정의한다. 두 E2E 모델에는 동일한 목표 라벨을 사용할 계획이다.

## 인프라 공간 관계와 시간 정렬

예비 공간 설계에서는 호모그래피로 영상 관측값을 지면 평면에 대응시킨다. 보행자의 추정 위치와 차량 위치를 공통 로컬 ENU 좌표계로 표현한 뒤, 차량 좌표계로 변환하는 구상이다.

시간 처리 계획에서는 영상의 촬영 타임스탬프를 유지하고 **시계 동기화**와 **움직임 보상**을 구분한다. 처리·송신·수신·융합·제어 단계의 타임스탬프를 활용해 추후 지연 시간과 메시지 최신성을 분석할 계획이다.

현재 카메라 배치, 지면 기준점, 독립적인 정확도 검증, 타임스탬프 표기·처리 규칙을 설계하고 있다.

데이터 수집 계획은 동일한 주행에서 차량 영상·차량 상태·인프라 관측 정보를 함께 기록하는 방식이다. 학습·검증·시험 데이터는 **주행 또는 세션 단위**로 분리할 계획이다. 계획한 시나리오는 보행자 부재, 차량 경로 안팎의 정지, 접근, 횡단, 이탈을 포함한다.

평가에서는 검출·감속 시점, 정지 여유, 최소 충돌 예상 시간, 충돌 발생 여부, 불필요한 제동을 살펴볼 계획이다. 추가된 인프라 정보와 주행 거동의 차이를 연결해 분석하는 것이 목표다.

## V2I 통신 방식 조사

Wi-Fi 기반 ROS 2/DDS를 포함해 인프라 컴퓨터와 차량 컴퓨터 사이의 통신 방식을 조사하고 있다. 차량이 보행자 시나리오 구간에 접근하는 동안 관측 정보가 얼마나 빨리 도착하고 메시지가 얼마나 일관되게 수신되는지 검토한다.

현재 비교 기준은 다음과 같다.

- **메시지 최신성:** 관측 시점부터 사용 시점까지의 시간.
- **전달 지연:** 송신 시점부터 수신 시점까지의 시간.
- **수신 연속성:** 수신 공백, 메시지 누락·순서 뒤바뀜, 재연결 시 동작.

전용 Wi-Fi 네트워크와 다른 연결 구성을 팀 논의 후보로 검토하고 있다. 이 작업은 현재 진행 중인 **조사·설계 단계**의 일부다.

## 후속 설계 과제

다음 단계에서는 통신 방식과 인터페이스를 구체화하고, 현장에서 카메라 가시성과 공간 정렬을 평가하며, 시간 지연과 제동 특성의 측정 방법을 정리하고, 두 모델을 비교할 데이터 수집·평가 절차를 준비한다. 이후 모델 학습과 축소 차량 폐루프 비교를 진행할 계획이다.
