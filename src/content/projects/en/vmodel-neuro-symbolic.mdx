## Project goal

The project combined ROS 2 decision-making and waypoint-following components with CARLA. My implementation covered Pure Pursuit for path tracking and longitudinal speed control, alongside the integration work required to connect these components to the simulation.

The Dream Semester project aimed to establish a working autonomous-driving loop. The implementation covered both the simulation interface and later adaptation toward a vehicle command interface.

## Outcome

**The autonomous-driving objective was not achieved, and the final code did not lead to an actual vehicle run.** Earlier closed-loop simulation work exposed unstable path tracking that persisted through the project's adjustments.

The project ended with the Dream Semester period. The repository preserves the final implementation and the investigation record.

## Integration work

The code retains two stages: earlier CARLA control implementations under `src/neuro_decision/archive`, and the later behavior, steering, and MCU bridge packages. The latter separate desired speed and steering angle from the vehicle-specific serial command format and include a mock inspection path.

## What I learned

The work made interface consistency a concrete debugging concern: target coordinates, steering units, input timing, and actuator commands all need to agree.

It also motivated more systematic experiment records: keeping input conditions fixed, changing one control setting at a time, and recording the resulting trajectory and commands together.
