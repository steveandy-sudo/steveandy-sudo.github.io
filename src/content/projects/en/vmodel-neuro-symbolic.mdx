## Project question and implementation

This Dream Semester project, originally titled **V-Model Neuro-Symbolic Driving**, aimed to connect ROS 2 driving decisions and waypoint following to a working autonomous-driving loop. My implementation focused on Pure Pursuit, longitudinal speed control, CARLA integration, and later adaptation of the vehicle-command interface.

## Debugging record

**Observation:** closed-loop simulation showed unstable path tracking. I investigated steering direction, lookahead, target smoothing, rate limiting, and command bounds. The project ended before a single root cause was conclusively isolated.

| Area investigated | Work carried out | Evidence needed to isolate its effect |
| --- | --- | --- |
| Steering direction and units | Checked and adjusted steering response | A fixed target with requested and observed turn direction |
| Lookahead and target geometry | Adjusted target-following parameters | Identical routes with target-point and trajectory overlays |
| Smoothing and rate limiting | Adjusted command filtering and change limits | Time-aligned steering before and after each change |
| Command bounds and interface | Adjusted output limits and adapted the command bridge | Input/output traces with units, saturation, and timestamps |

The available records do not isolate the effect of each adjustment on tracking error.

## What the code preserves

The project repository separates earlier CARLA implementations under `src/neuro_decision/archive` from later behavior, steering, and MCU bridge packages. The later steering node contains target-geometry handling, smoothing, bounds, and per-cycle steering limits. The bridge translates desired speed, steering angle, and state into the serial command format.

## Lessons and a better experiment

The main lesson was to make **target coordinates, steering units, timestamps, and command ownership** explicit before tuning the controller. Without matched trajectory and command records, the effect of individual adjustments remains difficult to establish.

For a future reconstruction, I would start with a straight path and one constant-radius turn, verify steering sign and units, and then vary one setting at a time. The record would pair target and actual trajectories with time-aligned commands, to measure how each setting affects tracking.
