## Research question

**How much additional safe-response distance can V2I provide in a blind-spot scenario?**

The study is designed around a pedestrian emerging from behind parked vehicles. Vehicle-mounted cameras may encounter the pedestrian only after the occlusion clears; the proposed infrastructure sensing is intended to provide an additional source of pedestrian information. Whether that information improves the response is a question for the planned experiments.

## Planned object-state interface

The proposed infrastructure message describes pedestrian object state using the following fields:

| Fields | Intended information |
| --- | --- |
| `x`, `y` | Pedestrian position |
| `vx`, `vy` | Pedestrian velocity |
| `confidence` | Confidence associated with the object state |
| `timestamp` | Time associated with the state |

These are **planned fields**. A message definition, coordinate-frame convention, synchronization method, or implemented communication interface is not claimed here.

## Experiment design

The planned comparison uses the same blind-spot scenario for two configurations:

1. **Camera-only E2E:** the vehicle-side camera-based driving configuration.
2. **V2I-assisted E2E:** the configuration augmented with the proposed infrastructure pedestrian state.

Distance to hazard, **d**, is the primary experimental variable. The design asks how the available distance affects safe response in the parked-car occlusion scenario.

## Planned evaluation

| Metric | Role in the comparison |
| --- | --- |
| Collision Rate | Compare collision outcomes across trials |
| Minimum TTC | Examine the closest time-to-collision condition |
| Braking Onset | Compare when braking begins |
| Stopping Distance | Compare distance associated with stopping |
| Success Rate | Compare successful scenario outcomes |

These are evaluation measures selected for the experiment, **not measured results**. Trial counts, operating conditions, and success criteria must be documented with the eventual experiment record.

## Current outcome

The current output is the system and experiment design. Implementation and closed-loop validation remain planned, and the research question remains open.
