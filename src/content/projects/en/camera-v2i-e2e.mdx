## Research question

**How much additional safe-response distance can infrastructure-camera information provide when a pedestrian emerges from behind a parked vehicle?**

The working hypothesis is that earlier pedestrian information may allow an E2E driving model to brake sooner. The comparison must also examine whether communication delay or uncertain detections reduce that benefit. This project is currently a system and experiment design; implementation and closed-loop trials are the next stages.

Camera sensing was selected after considering smartphone, radar, LiDAR, and camera options, with deployment feasibility and semantic information as design considerations.

## Comparison and controls

| Experiment element | Planned choice |
| --- | --- |
| Baseline | Camera-only E2E driving |
| Comparison | The same driving setup augmented with infrastructure pedestrian state |
| Primary variable | Distance to the hazard when the scenario begins |
| Matched conditions | Road geometry, ego speed, pedestrian motion, occlusion, and stopping criteria |
| Follow-up sensitivity checks | Message delay, missing messages, and object-state uncertainty |

The base model, fusion architecture, trial counts, and parameter ranges will be fixed before data collection. Matching the driving setup makes the contribution of infrastructure information the focus of the comparison.

## Planned interface and evaluation

The proposed message contains pedestrian `x`, `y`, `vx`, `vy`, `confidence`, and `timestamp`. Coordinate-frame conventions and synchronization must be defined before integration.

| Measure | Interpretation |
| --- | --- |
| Collision rate | Fraction of matched trials ending in a collision |
| Minimum time to collision | Closest estimated time-to-collision condition during the encounter |
| Braking onset | When the vehicle begins braking relative to the hazard |
| Stopping distance | Distance traveled from braking onset to stopping |
| Scenario success rate | Fraction meeting the predefined safety and completion criteria |

These are planned measurements. Results will include operating conditions and trial counts so that changes in response can be interpreted alongside failure cases.

## Next milestone

Build one reproducible occlusion scenario and run the camera-only baseline before adding the infrastructure input. The first comparison should establish the information timing and braking response in a controlled setting, followed by the delay and uncertainty checks.
